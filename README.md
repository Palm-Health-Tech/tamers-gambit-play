# Blight Siege

A free browser roguelike set in the world of Tamer's Gambit. Build a deck of creature cards, play them as towers along the road, and climb three acts against the Blight.

Play it here: https://palm-health-tech.github.io/tamers-gambit-play/

Clear acts to earn Tamer Codes. They unlock cosmetic rewards in the full game.

The page is one static file with no tracking. Your progress and your Museum are saved in your own browser.
